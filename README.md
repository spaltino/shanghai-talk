# 상하이 소통카드 · 上海沟通卡

중국 상하이에서 바로 보여주는 **초단순 중국어 소통 카드**입니다. 2026-11-26(목) 상하이 당일치기 마운자로 5mg 원정(런지병원 동원 12:15 예약)에 맞춰 만들었습니다.

**라이브**: https://spaltino.github.io/shanghai-talk/

## 쓰는 법 (3단계)

1. **장소** — 병원 · 약국 · 택시/이동 · 공항/입출국 · 식당/편의점 · 긴급/도움
2. **상황** — 그 장소에서 실제로 부딪히는 순서 (예: 병원 → 접수 → 진료 → 수납 → 약 받기)
3. **카드** — 자주 쓰는 순서대로 배열. 카드를 누르면 **화면 가득 확대**(흰 배경·검은 글씨)되고, 좌우 스와이프나 이전/다음 버튼으로 이어서 보여줄 수 있습니다. 확대 화면은 상대방에게 폰을 내밀어 보여주는 용도입니다.

카드 한 장에는 큰 중국어 간체 문장 + 병음 + 한국어 뜻이 있고, 상대방이 되물을 때 쓸 답변 카드는 위에 예상 질문(`您有预约吗？`)을 작게 함께 보여줍니다.

## 구성

- 6개 장소 · 24개 상황 · **206장** 카드
- 중국어 간체 기준. 지도·로그인·설치 없음.

## 중국 현장 주의

- 외부 CDN·폰트·분석 스크립트를 전혀 쓰지 않습니다(시스템 폰트 + 인라인 CSS/JS). 중국 본토에서 구글 리소스가 막혀도 그대로 뜹니다.
- 한 번 열면 서비스 워커가 파일을 저장해 **인터넷 없이도** 열립니다(출국 전 제주에서 한 번 열어 두세요). 홈 화면에 추가하면 앱처럼 뜹니다.
- 중국 본토에서 `*.github.io` 접속이 느리거나 막히는 경우가 있습니다. 그래서 오프라인 저장을 권합니다.

## 파일

- `index.html` — 앱 전체(데이터 포함, 단일 파일)
- `sw.js` — 오프라인 캐시
- `manifest.json`, `icon.svg` — 홈 화면 추가용

## 고치기

`index.html`의 `PLACES` 배열만 수정하면 됩니다. 카드 형식:

```js
C('중국어 문장', 'pīnyīn', '한국어 뜻', '상대방 예상 질문(선택)')
```

수정 후 `sw.js`의 `CACHE` 버전을 올려야 이미 열어 본 기기에 새 내용이 반영됩니다.
