# 상하이 소통카드 · 上海沟通卡

중국 상하이에서 바로 보여주는 **초단순 중국어 소통 카드**입니다. 병원·약국·택시·공항·식당·긴급 상황에서 폰을 내밀어 보여주면 되는 문장만 모았습니다.

**라이브**: https://spaltino.github.io/shanghai-talk/

## 쓰는 법 (3단계)

1. **장소** — 병원 · 약국 · 택시/이동 · 공항/입출국 · 식당/편의점 · 긴급/도움
2. **상황** — 그 장소에서 실제로 부딪히는 순서 (예: 병원 → 접수 → 진료 → 수납 → 약 받기)
3. **카드** — 자주 쓰는 순서대로 배열. 카드를 누르면 **화면 가득 확대**(흰 배경·검은 글씨)되고, 좌우 스와이프나 이전/다음 버튼으로 이어서 보여줄 수 있습니다. 확대 화면은 상대방에게 폰을 내밀어 보여주는 용도입니다.

각 카드 오른쪽의 **🔊 버튼**을 누르면 화면 전환 없이 그 자리에서 중국어 문장만 소리로 읽어 줍니다(다시 누르면 정지). 확대 화면 아래 **🔊 듣기**와 **속도(보통 0.95x / 천천히 0.7x)** 로 연습할 수 있습니다. 음성은 기기(브라우저)에 내장된 음성 합성을 쓰므로 외부 API·인터넷 없이 중국에서도 동작합니다(아이폰 설정 → 접근성 → 콘텐츠 말하기 → 음성에서 중국어 음성을 한 번 받아 두면 좋습니다).

카드 한 장에는 큰 중국어 간체 문장 + 병음 + 한국어 뜻이 있고, 상대방이 되물을 때 쓸 답변 카드는 위에 예상 질문(`您有预约吗？`)을 작게 함께 보여줍니다.

## 구성

- 6개 장소 · 24개 상황 · **212장** 카드
- 병원: 국제의료부 접수 → 진료·처방 요청 → 수납·영수증(发票) → 약국에서 약 받기
- 약국: 처방전 제시·구매 문의 → 재고·가격 확인 → 복용법·보관 → 결제·영수증
- 택시: 목적지 보여주기 → 요금·결제 → 영수증·하차 → 길·지하철 묻기
- 공항: 입국 심사 → 출국·체크인 → 보안·세관 → 공항 시설
- 식당·편의점: 편의점 → 식당 주문 → 카페 → 결제·기타
- 긴급·도움: 몸이 아플 때 → 길을 잃었을 때 → 도움 요청 → 화장실·사진 부탁

> 사진은 Wikimedia Commons(CC BY-SA 4.0 · CC BY 4.0)에서 가져왔고 각 사진 아래에 촬영자·라이선스를 표기했습니다.
- 중국어 간체 기준. 지도·로그인·설치 없음.
- 🔊 음성은 Web Speech API(`speechSynthesis`, `zh-CN`)만 사용 — 외부 TTS 서버 없음.

## 중국 현장 주의

- 외부 CDN·폰트·분석 스크립트를 전혀 쓰지 않습니다(시스템 폰트 + 인라인 CSS/JS). 중국 본토에서 구글 리소스가 막혀도 그대로 뜹니다.
- 한 번 열면 서비스 워커가 파일을 저장해 **인터넷 없이도** 열립니다(출국 전 한 번 열어 두세요). 홈 화면에 추가하면 앱처럼 뜹니다.
- 중국 본토에서 `*.github.io` 접속이 느리거나 막히는 경우가 있습니다. 그래서 오프라인 저장을 권합니다.

## 파일

- `index.html` — 앱 전체(데이터 포함, 단일 파일)
- `sw.js` — 오프라인 캐시
- `manifest.json`, `icon.svg` — 홈 화면 추가용
- `assets/banner.webp`, `assets/banner.png` — 홈 상단 배너
- `assets/metro/`, `assets/gongli/`, `assets/linyi-route-map.jpg` — 이전 동선 가이드용 현장 사진·도해. 지금 화면에서는 쓰지 않으며 오프라인 캐시에도 넣지 않습니다.

## 고치기

`index.html`의 `PLACES` 배열만 수정하면 됩니다. 카드 형식:

```js
C('중국어 문장', 'pīnyīn', '한국어 뜻', '상대방 예상 질문(선택)')
```

수정 후 `sw.js`의 `CACHE` 버전을 올려야 이미 열어 본 기기에 새 내용이 반영됩니다.
